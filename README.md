# Jeoparty

Quiz in stile Jeopardy per serate tra amici: in italiano, offline, su un solo schermo, con un conduttore.

## Avvio rapido

```powershell
npm start          # oppure doppio clic su start.bat: si apre http://localhost:3456
npm run validate   # controlla le domande
npm test           # test automatici
```

Requisiti, regole e tasti: [INSTRUCTIONS.md](INSTRUCTIONS.md).
